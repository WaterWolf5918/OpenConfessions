# Open Confessions
A Discord bot that allows users to semi anonymously confess random things to a channel and also acts as a alternative to the existing semi paid confessions discord bot.


## Features 
* Supports multiple confession channels 
* Support for a confessions logging channel 
* Supports color confessions and replies. 

## Running requirements 
* Deno 2.7.14
* Discord bot token  
* Discord channels with correct permissions
> [!NOTE]
> The bot does not try to fix channel permissions and will fail if you don't give channels, the bot, or role the correct permissions.
